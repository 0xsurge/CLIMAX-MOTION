# Motion film prompt template: no URL yet (photos + brand name)

How to use: copy everything between the lines, replace each [BRACKET], delete lines marked (optional), and paste it into a new message with your photos and logo attached. Anything in (parentheses) is what I will assume.

---

<inputs>
Brand: [name]
What it does: [one line]
Photos: [uploaded, 8-12 for 30 s+, about 5 for 15-20 s, 2000 px or larger on the long side]
Logo: [uploaded PNG/SVG with transparent background / none yet, you set the name as a placeholder wordmark]
Product UI screenshots: [uploaded / none]   (optional, I never redraw UI that exists)
Copy (exact words on screen): [headline], [3 to 6 short labels], [call to action]   (optional, otherwise you draft and I approve)
Colours / fonts you like: [...]   (default: sampled from the photos, one accent colour, one display face + one UI face, I tell you which)
Song: [uploaded / "pick one" / "synthesize"]   (optional)
Reference video: [uploaded]   (optional, I match craft, not brand)
</inputs>

<direction>
Story in one line: [what the film says about the brand]
Mood: [warm / cool / dark / bright / editorial / playful]   (default: from the photos)
Motion language: [continuous morphs / hard cuts on the beat / mix]   (default: continuous, no crossfades)
Effects: [masks, iris, goo, zooms, liquid glass, 3D tilt, none]   (pick any, without UI the film leans on photo grids, masks and big type)
Never: [your dislikes]   (house bans always apply)
Loop: [yes, last frame equals first / no]
</direction>

<structure>
Length: [seconds]   (default: 30)
Aspect: [16:9 / 1:1 / 9:16 / all three]   (default: 16:9 plus 1:1 and 9:16 exports)
Tempo: [BPM / match the song]
Beats: you propose   (I draft a beat map from the photos for your OK)
Ending: [logo + tagline / returns to the first frame / other]
</structure>

<build>
Sound: [downloaded Mixkit SFX / synthesized / none]   (default: downloaded, on the measured beat grid)
Deliverables: [mp4 + poster + contact sheet]   (default)
(fixed: Playwright, 60 fps, H.264 CRF 16, -14 LUFS, true peak under -1 dBTP, checks and 8+ scores)
</build>

<gotchas>
Placeholders: anything I invent (wordmark, palette, fonts, copy) is marked so you can swap it later.
Licences: [say if any photo, song or font is restricted]   (optional)
</gotchas>

<start>
Ask for anything missing. Then show the beat map and 4 stills for my OK before writing the full film.
</start>

---

Minimum to get started: Brand, What it does, Photos, Length, Aspect. Beats stays "you propose".
