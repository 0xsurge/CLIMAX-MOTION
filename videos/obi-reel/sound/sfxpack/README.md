# SFX pack (Mixkit, Mixkit Sound Effects Free License: free for commercial use, no attribution required)
Sorted by measurement (length, attack position, brightness, sustain):
- drone/   low sustained beds (trimmed to 30 s), for under sections
- impact/  short hits with the peak at the start: subtle landings, sub-hits
- riser/   build-ups whose peak is near the end: into a reveal
- sweep/   short noisy passes (whoosh family): use sparingly, the user dislikes swishes on movement
- ui/      very short ticks, clicks, bleeps
All files loudness-matched to about -20 LUFS. PACK.json lists the source id of every file.
Sources not yet used: Freesound (needs an API key; only CC0 sounds are safe), Pixabay (downloads may be blocked here).
